# Требования к системе «Электронный дневник»

| ID | Требование | Приоритет |
|----|------------|-----------|
| FR-01 | Преподаватель выставляет оценки и отмечает посещаемость по каждому занятию | Высокий |
| FR-02 | Студент видит свои оценки и пропуски в личном кабинете | Высокий |
| FR-03 | Куратор группы формирует ведомость успеваемости за период | Средний |
| FR-04 | Учебная часть загружает расписание и списки групп из 1С | Средний |
| NFR-01 | Персональные данные обрабатываются в соответствии с 152-ФЗ | Высокий |
| NFR-02 | Страница журнала открывается не дольше 2 секунд при 300 одновременных пользователях | Средний |

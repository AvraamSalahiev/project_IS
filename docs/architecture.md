# Архитектура системы «Электронный дневник»

## Компоненты

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| Веб-клиент | HTML/JS, адаптивная вёрстка | Интерфейс преподавателя, студента и куратора |
| Сервер приложений | Python | Бизнес-логика: оценки, посещаемость, ведомости |
| База данных | PostgreSQL | Хранение журналов, справочников и учётных записей |
| Модуль интеграции | Обмен с 1С | Ночная загрузка расписания и списков групп |
| Резервное копирование | pg_dump + cron | Ежедневные копии БД, хранение 30 дней |

## Схема взаимодействия

```
[Браузер] --HTTPS--> [Сервер приложений] --SQL--> [PostgreSQL]
                              |
                              +--обмен 02:00--> [1С:Колледж]
```

## Размещение

Сервер колледжа под управлением Astra Linux. Доступ из внешней сети открыт только по HTTPS (порт 443). Персональные данные остаются в контуре колледжа, что соответствует требованию NFR-01.

# Электронный дневник колледжа

Учебный проект внедрения информационной системы «Электронный дневник» в колледже. Система заменяет бумажные журналы: преподаватели выставляют оценки и отмечают посещаемость, студенты и родители видят успеваемость в личном кабинете. Репозиторий служит единой точкой правды для всех артефактов проекта — документации, кода, тестов и управленческих материалов.

## Структура папок

```
project_IS/
├── docs/            # проектная документация
│   └── requirements.md
├── src/             # код и конфигурации
│   └── config.yaml
├── tests/           # тестовые материалы
│   └── test_cases.md
├── management/      # управленческая информация
│   └── project_plan.md
└── README.md        # описание проекта
```

## Как использовать

1. Клонировать репозиторий: `git clone <URL репозитория>`.
2. Требования к системе лежат в `docs/requirements.md`, план-график — в `management/project_plan.md`.
3. Параметры развёртывания описаны в `src/config.yaml`, тест-кейсы для приёмки — в `tests/test_cases.md`.
4. Любое изменение вносится отдельным коммитом с осмысленным сообщением.
